# PLATE CLUB

Коллекционная игра с автомобильными номерами России и Беларуси: 48 кейсов (включая 4 элитных) с шансами по кнопке «i», серверная рулетка, апгрейд номеров с колесом шанса, уровни, бонусы и промокоды, топ аккаунтов, общий рынок, проверка подлинности каждого номера по ID. Интерфейс на русском и английском.

## Как устроено

| Часть | Где | Что делает |
|---|---|---|
| Исходники интерфейса | `src/*.js` → `node tools/build-app.mjs` → `public/app.js` | Редактировать `src/`, затем собрать (готовый `public/app.js` уже в репозитории) |
| Сайт | `public/` | Тёмный интерфейс, хромовый логотип, CS-рулетка с motion blur, голографическая галочка, звук (по умолчанию выключен) |
| API | `server/app.mjs` → `netlify/functions/api.mjs` | Регистрация, сессии, кейсы, рынок, проверка, кошелёк, платежи |
| Игровая спецификация | `server/game.mjs` | 38 кейсов в 6 категориях, шансы, цены, скидки дня, регионы РФ и РБ, редкости — единый источник для сервера и сайта |
| База данных | `netlify/database/migrations/` | Postgres (Netlify Database), применяется автоматически при деплое |
| Фон главной | `public/img/hero-chrome*.jpg` | «Жидкий хром» в стиле логотипа, сгенерирован под сайт (десктоп и телефон) |
| Бренд | `public/brand/`, генератор `tools/brand.mjs` | Хромовый логотип `logo-chrome*.png`, favicon и иконки из него |
| Тесты | `test/run.mjs` | 147 проверок сценариев на настоящем Postgres |

Баланс, владельцы номеров и объявления хранятся только в базе. Браузер ничего не решает сам.

## Деплой на Netlify

1. Залить папку на Netlify одним из способов:
   - **Через GitHub:** app.netlify.com → Add new project → Import from Git → выбрать репозиторий `plate-club`. Дальше каждый push публикуется сам.
   - **С компьютера:** в папке проекта `npx netlify-cli deploy --prod`.
2. В Netlify → Project configuration → Environment variables добавить:

| Переменная | Обязательна | Зачем |
|---|---|---|
| `PLATE_SEAL_SECRET` | да | Секрет для подписи номеров (32+ символа). Без него кейсы и проверка не работают. Не менять после запуска — иначе старые номера перестанут проходить проверку. |
| `RESEND_API_KEY`, `MAIL_FROM` | для писем | Подтверждение email и восстановление пароля через resend.com. Без них сайт честно сообщает, что письма не настроены. |
| `ADMIN_SETUP_CODE`, `ADMIN_INITIAL_GRANT` | для админа | Секретный код включения админ-панели и стартовый баланс админа (один раз). |
| `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET` | для пополнения | Оплата картой через Stripe Checkout. Без них пополнение выключено. |

3. Для Stripe: в панели Stripe создать webhook на `https://<ваш-домен>/api/payments/webhook/stripe` с событиями `checkout.session.completed` и `checkout.session.expired`. Сначала проверить в тестовом режиме (`sk_test_…`), потом переключить на боевые ключи.

База данных создаётся Netlify автоматически при первом деплое, потому что в `package.json` есть `@netlify/database`.

## Правила экономики

- 50 PLT при регистрации — один раз на аккаунт. Повторно не начисляется: это гарантирует уникальный индекс в базе.
- Уровни: XP = PLT, потраченные на кейсы; уровень n — 50·(n−1)·n XP; за каждый новый уровень 10 PLT.
- Апгрейд: шанс = 90% × (оценка номера / оценка цели), от 1% до 75%; при проигрыше номер сгорает (статус BURNED), при победе выпускается номер выбранной редкости в том же регионе. Бросок делает сервер.
- Топ: стоимость аккаунта = баланс + оценка номеров, админы не участвуют.
- Оценки v2: Обычный 20, Хороший 60, Редкий 500, Элитный 2 500, Грааль 15 000 (× регион). Номера, выпущенные раньше, сохраняют старую оценку (колонка `vv`) и проходят проверку.
- STARTER стоит 100 PLT; цены кейсов считаются из ожидаемой оценки содержимого. Категория «Элита» (только элитные и Граали) — 5 800–13 050 PLT, в 2–3 раза дороже остальных. Каждый день три кейса дешевле на 5, 7 и 10% (одинаково для всех, смена в 00:00 UTC).
- Шансы: в дешёвых кейсах редкий и выше — около 4%, Грааль — 0,05%. Основная масса — «Хороший».
- Белорусские номера стоят 60% от российских той же редкости.
- Каждая комбинация существует максимум в 2 экземплярах (уникальный индекс combo+copy в базе).
- Плюшки: бонус дня — 10 PLT каждый день, награды за 12 достижений и за уровни — по 10 PLT, промокоды (PLATECLUB 10, LUCKY7 7, MINSK 10; новые создаются в админке).
- Пополнение: 100, 250, 500, 1 200, 3 000, 7 500 и 20 000 PLT.
- Комиссия рынка 5% платит продавец; она зачисляется на аккаунт администратора (переменная `FEE_RECIPIENT` — ник получателя, иначе первый админ). Банк выкупает номера за 60% справочной стоимости.
- Ежедневных бонусов и бесплатных кейсов нет.

## v9 — экономика и рынок (16.10.2026)
- **Шансы v3.** Лучше дропы во всех кейсах; у кейсов «Элита» +3 п.п. Грааля. Цена кейса = средняя оценка ÷ RTP: дешёвые 92–93%, Узоры/Премиум 90%, Топ/Легенды 87–88%, Элита 85%. «Старт» — фиксированные 100 PLT.
- **Оценка номера v3.** Базы: обычный 25, хороший 80, редкий 500, элитный 2500, Грааль 15000. Свойства номера умножают оценку: блатная серия ×2, низкий номер ×1.5, две семёрки ×1.3, парные буквы ×1.3. Старые номера сохраняют свою оценку (`plates.vv`).
- **Маркетмейкер `PlateClubMarket`.** Держит на рынке 36 лотов обычных номеров по 84–145% оценки. Непроданные лоты дешевеют на 6% каждые 30 минут, но не ниже 82% оценки.
- **Скупщик.** Каждый день спрашивает 3 вида номеров и платит за них 115% оценки — до 3 номеров в день на игрока. Купленное перевыставляет по 100–125%, поэтому бесконечного цикла нет.
- **Прибыль.** У каждого номера хранится цена покупки (`plates.paid`), в коллекции видны прибыль и убыток.
- **Рынок.** Сортировка «Выгодные», фильтры «игроки / рынок», статистика рынка.

## v10: панель управления и поддержка (16.10.2026)
- **Панель `#/admin/<раздел>`.** Разделы: Обзор, Участники, Сообщения, Рынок, Кейсы, Промокоды, Настройки, Журнал.
- **Участники.** Список всех игроков и карточка игрока: PLT, номера, операции, обращения. Из карточки можно отправить или списать любую сумму, подарить номер любой редкости, написать игроку, заблокировать или разблокировать.
- **Бонус и сообщение всем игрокам** — одним действием.
- **Поддержка `#/support`.** Игрок пишет обращение и видит ответ в переписке. Непрочитанные отмечаются точкой в шапке и счётчиком в панели.
- **Настройки** хранятся в таблице `settings` и применяются без деплоя: бонус за регистрацию, ежедневный бонус, процент выкупа банком, комиссия рынка, условия скупщика, число лотов маркетмейкера, объявление на сайте, цена и видимость каждого кейса.
- **Маркетмейкер** теперь держит на рынке 60 лотов вместо 36.

## v11: игры (16.10.2026)
Все игры собраны на странице `#/games`.

### Кейс-баттл (`#/battles`, `#/battle/<id>`)
- 2–4 игрока, 1–5 раундов одного кейса.
- Вход равен цене кейса × число раундов.
- Победитель — у кого больше сумма оценок выпавших номеров; он забирает все номера. При ничьей победитель выбирается жребием.
- Создатель может позвать ботов на свободные места; если побеждает бот, номера уходят маркетмейкеру.
- Отмена открытого баттла возвращает PLT всем участникам.

### Коллекции (`#/sets`)
- 32 сета: регионы, узоры, серии, редкость, количество номеров.
- Награда за сет выплачивается один раз, номера остаются у игрока.
- Собранные сеты видны значками в профиле.

### Обмен (`#/swap`, `#/swap/new?to=<ник>&want=<id>`)
- До 6 номеров и доплата в PLT с каждой стороны, без комиссии.
- При принятии сервер заново проверяет владение номерами и балансы.

### Аукцион дня (`#/auction`)
- Каждый день разыгрывается один номер редкости «редкий» и выше.
- Стартовая цена — 50% оценки, шаг — 5% оценки.
- Ставка замораживает PLT; если ставку перебили, PLT возвращаются.
- Ставка в последние 5 минут продлевает аукцион на 5 минут.
- Номер переходит к победителю; если ставок не было, номер уходит на рынок.
