# Mise — кухня с помощником

Минималистичное приложение (PWA, ставится на экран телефона, работает офлайн). Без сборки и зависимостей.

- **Что в холодильнике?** Продукты вводятся текстом или выбираются чипами, плюс настроение: солёное / сладкое / спорт / новое. Приложение выдаёт лучший рецепт, список «можно сейчас» и «почти хватает» с подсказками, чем заменить недостающее.
- **Моя техника.** Рецепты фильтруются по тому, чем вы готовите. Режим «Ничего нет» оставляет только рецепты без техники.
- **Помощник (мини-ИИ).** Понимает продукты в любых падежах, «за 15 минут», «без духовки», «без молока», «чем заменить сметану», «ещё». Работает на устройстве, без сервера.
- **95 рецептов:** торты, сладкое, солёное, коктейли, спорт, остальное. Шаги с таймерами, советы, порции, список покупок, избранное, режим готовки с экраном без затухания.

Запуск: `python3 -m http.server -d mise 8000`, затем http://localhost:8000. Тесты: `node mise/test/engine.test.mjs`.
Рецепты лежат в `js/data/recipes/*.js`, продукты и замены — в `js/data/ingredients.js`.
