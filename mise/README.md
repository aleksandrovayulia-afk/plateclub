# Mise

Приложение-кухня на русском, английском и испанском: почти 16 000 рецептов, подбор по продуктам из холодильника, помощник, план питания, список покупок, режим готовки с таймерами.

- Без сборки: ES-модули, `index.html` + `js/app.js`. Работает офлайн (service worker), данные хранятся только на устройстве.
- Запуск: любой статический сервер в папке `mise/` (например `npx serve mise`).
- Тесты: `node test/data.test.mjs` (целостность рецептов и словарей), `node test/i18n.test.mjs` (все ключи интерфейса есть в трёх языках), `node test/assistant.test.mjs` (помощник на трёх языках).

## Устройство
- `js/data/ingredients.js` — 172 продукта с названиями, падежами и региональными вариантами (Испания / Латинская Америка, US / UK).
- `js/data/recipes/` — 95 авторских рецептов, «семейства» шаблонов и перекрёстные семейства (`families/combo*.js`): основа × гарнир × приправа даёт отдельные рецепты на трёх языках. Шаги собираются лениво.
- `js/music.js`, `js/musicui.js` — музыка (три стиля, генерируется на устройстве), мини-плеер, таймер сна.
- `js/engine.js` — поиск, подбор по холодильнику, фильтры по технике и диете.
- `js/assistant-core.js` — помощник: разбирает запрос на трёх языках и работает прямо на устройстве, это не языковая модель.
- `js/i18n/*.js` — строки интерфейса.

Фото блюд: Pexels (свободная лицензия), по одному на вид блюда, лежат в `img/food/`. Музыка генерируется на устройстве (WebAudio), файлов нет.

Рецепты написаны заново, они не скопированы с сайтов-источников. Названия и обороты проверялись по словарям (RAE и др.), но носитель языка всё равно найдёт, что поправить.
